# Roadmap

## Done

- Programs, vulnerabilities (report and submission in one form and one page) and evidence with full CRUD
- Quick status and reward actions that date themselves; unfiled reports
- Bounty tracking: lifecycle dates, payouts per currency, paid / unpaid, program re-ratings
- Bounty tab: statistics per currency and a rewards ledger
- Report templates
- Ranked search with a query language and command palette
- Markdown files and import
- Tags and an AI export as JSON or Markdown, with redaction
- Agent API over WebMCP and MCP

## Next

1. Export and import of the whole workspace as a ZIP bundle
2. Duplicate detection
3. PostgreSQL support
4. TOTP, multiple users and an audit log
5. S3-compatible evidence storage
